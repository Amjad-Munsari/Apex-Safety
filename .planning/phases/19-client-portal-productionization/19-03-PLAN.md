## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-07 | Elevation of Privilege (IDOR) | /client/assignments/[id]/submission server route | mitigate | RLS is primary; defense-in-depth `.eq("client_id", ctx.client_id)` plus an explicit `submission.client_id !== ctx.client_id → notFound()` check. | T-19-08 | Tampering | Read-only viewer | mitigate | No submit handler, no ref, and a pointer-events-none wrapper — the viewer cannot mutate or re-submit the pinned submission. |
| T-19-09 | Information Disclosure | Pinned schema fetch | mitigate | Only the `schema_json` for the submission's own `template_version_id` is fetched; the renderer is seeded solely with this submission's `answers_json`. |
| T-19-10 | Spoofing | path param injection | mitigate | UUID_RE guard rejects non-UUID `[id]` before any DB query, preventing malformed-id probing. |
