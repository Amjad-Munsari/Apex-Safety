# Phase 2: Form Prerequisites - UI Specification

**Gathered:** 2026-04-29
**Status:** ## UI-SPEC VERIFIED

## 1. Visual Direction & Brand Alignment

### Aesthetic: High-Fidelity Editorial
- **Typography:**
  - Headings: `Outfit` (Sans-serif), medium weight, tight tracking.
  - Body: `Inter` (Sans-serif), optimized for legibility on tablets.
  - Labels: Upper-case, 0.75rem, letter-spaced (0.05em) for a premium "pro tool" feel.
- **Color Palette:**
  - Background: Slate 950 (Deep dark mode).
  - Cards: Slate 900 with subtle 1px border (Slate 800).
  - Accent: Vibrant Amber/Orange (The "888" safety color) for action buttons and recording indicators.
- **Micro-interactions:**
  - Hover: Subtle scale-up (1.02x) on form cards.
  - Focus: Ring-2 ring-amber-500 on inputs.

## 2. Layout & Interaction Design

### Form Structure
- **Container:** Centered max-width column (3xl / 48rem).
- **Cards:** Each form field is a discrete card with padding (p-6).
- **Spacing:** Relaxed vertical rhythm (space-y-6).

### Specialized Interactions
- **Microphone Button:**
  - Position: Right-aligned within text area/input wrappers.
  - State (Idle): Gray icon, subtle ghost button.
  - State (Recording): Amber pulse animation, icon changes to 'stop' or 'waveform'.
  - Feedback: "Transcribing..." ghost text overlay while processing.
- **Photo Upload:**
  - Grid-based thumbnail preview.
  - Progress ring on each thumbnail during conversion/compression.
  - Success checkmark once JPEG < 1.5MB is verified.

## 3. Copywriting & Content
- **Placeholders:** "Tap mic to narrate observation..." / "Upload fuse box photo (JPEG/HEIC)..."
- **Empty States:** "No photos attached. High-quality JPEG required for compliance."
- **Draft Status:** "Draft synced to cloud 2m ago" (Subtle text in footer).

## 4. Components & Atoms
- `FormCard`: Wrapper with consistent border/shadow.
- `MediaButton`: Circular button with pulse variant.
- `SyncStatus`: Sticky footer element with "Pulse" dot.
