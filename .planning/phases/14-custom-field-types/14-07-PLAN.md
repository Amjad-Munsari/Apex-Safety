## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin user → builder UI | Admin trust boundary — builder writes to the schema_json which is then version-pinned on save (Phase 13 13-02 server actions are the enforcement layer; no new server-side surface in this plan) |
| PropertiesPanel computedInputs dropdown → schema | Selected entity IDs flow into computedInputs attribute; these IDs must exist in the same schema (admin chooses from the list; deletion of a referenced entity is handled by the renderer's "Computed field not configured" pending state, not by a strict referential check) |
| Adding attachPhotosAttribute to existing entities → existing schemas | Backwards-compatible because attachPhotos defaults to false; existing answers_json continues to validate; schema_json round-trip is clean |
