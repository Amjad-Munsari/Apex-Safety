<!-- coltorapps API contracts the executor needs. Source: 13-RESEARCH.md Patterns 1-2, Code Examples. -->
<!-- The executor should use these directly. coltorapps is new to this codebase — no analog exists. -->

createEntity({ name, attributes, validate }) — defines a field type. `validate(value, context)` receives `context.entity.attributes`; unset attributes are `undefined` (RESEARCH.md Pitfall 4 — always coerce with `?? false` / `?? ""`).

createAttribute({ name, validate }) — defines a reusable attribute. `validate(value)` throws on invalid, returns normalized value on success.

createBuilder({ entities: [...] }) — combines entities into a builder instance.

Schema<typeof formBuilder> — the TypeScript type of a coltorapps schema: `{ entities: { [uuid]: { type, attributes } }, root: [uuid, ...] }`.

validateSchema(rawSchema, formBuilder) — async; returns `{ success: true, data } | { success: false, reason: { code } }`.

builderStore.addEntity({ type, attributes }, { parentId }) — adds an entity; with `parentId` the entity nests inside that sectionGroup and is NOT in `root`.
</interfaces>
