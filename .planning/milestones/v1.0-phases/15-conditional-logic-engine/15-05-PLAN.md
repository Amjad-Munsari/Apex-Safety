<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client submit → submitAssessmentAction | Hostile client could submit values for hidden fields hoping to land them in `answers_json`. stripHiddenAnswers is the defence. |
| Client save → saveDraftAction / publishTemplateAction (admin AND customer) | Hostile client could submit a cyclic schema to trigger runtime DoS in the renderer. validateRuleGraph rejects before INSERT. |
| answers_json → runReportDraftGeneration → OpenAI prompt | If hidden values leaked into answers_json, they would leak into the AI prompt. Server-side scrub closes this end-to-end. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05-01 | Information Disclosure | answers_json content | mitigate | stripHiddenAnswers runs AFTER validateEntitiesValues and BEFORE the UPDATE; hidden subtree (D-01 cascade) cannot reach the DB. Tests in server-scrub.test.ts verify the key is absent from the written payload for hidden fields and per-instance repeatingSection children. |
| T-15-05-02 | Denial of Service | Interpreter render loop (server-distributed) | mitigate | validateRuleGraph rejects cyclic schemas at SAVE time AND PUBLISH time on BOTH surfaces. A hostile client cannot persist a cyclic schema; even if they bypassed the UI, the server-side guard throws before INSERT. |
| T-15-05-03 | Tampering | Surface asymmetry exploit | mitigate | Open Question #3 resolved: both admin and customer template paths receive the identical guard. Acceptance criteria explicitly counts the call sites (4 total: 2 admin + 2 customer). |
| T-15-05-04 | Information Disclosure | AI report prompt content | mitigate | runReportDraftGeneration in the after() callback reads `answers_json` post-scrub. No path exists for hidden values to enter the OpenAI prompt. Tested transitively (server-scrub test confirms `answers_json` is scrubbed before write; AI path is unchanged). |
| T-15-05-05 | Repudiation | Cycle-rejection error | mitigate | Error message is structured JSON (`kind: "RuleGraphInvalid"` + cycles + scopeErrors). Next.js server-action telemetry already captures the throw via the existing error pipeline; admin sees a parseable error in the builder UI (plan 15-07). |
| T-15-05-06 | Spoofing | sourceEntityId pointing to another template | mitigate | validateRuleGraph operates only on the current template's schema. Cross-template refs become orphans (advisory only, do NOT block save) and at runtime evaluateRule returns false for unknown keys (plan 15-02). No cross-template data path exists by construction. |
</threat_model>
