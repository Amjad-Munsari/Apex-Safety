Key contract constraints (from migration 010 lines 60-67):
- coltorapps validateSchema enforces parent/child consistency (EntityParentMismatch): a container entity MUST list its children, not just rely on the child's parentId

- The root array contains only top-level entity IDs (children's IDs are nested inside their parent's children array AND carry a parentId — never in root)
