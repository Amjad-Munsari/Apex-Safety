<objective>
Close §D from 16-UAT.md: rewrite the two fill clients onto the real `InterpreterRenderer` (coltorapps-based) instead of the hallucinated `@/components/forms/form-renderer`. This unblocks `npm run build` (drops from 9 errors → 7 pre-existing) and unblocks customer UAT §A.

This is a gap-closure plan, not a feature. No new product surface — only the wiring that 16-04 and 16-06 designed against a fictional component.

**Architecture:**
1. The RSC pre-creates a `form_submissions` draft row (so the existing Phase 14 specialty renderers — signature, multi-photo, geolocation — have a real `submissionId` for their upload paths).
2. `InterpreterRenderer` gets a new optional `onSubmit?: (values) => Promise<void>` prop. When supplied, it overrides the hard-wired `submitAssessmentAction(submissionId, values)` call.
3. The fill clients become thin wrappers: surface chrome + InterpreterRenderer + submit button.
4. The submit server actions switch from INSERT → UPDATE the existing draft (assignment status transition stays on the assigned-fill action).

Output: 2 new files removed in spirit (rewritten), 2 RSC pages updated, 1 InterpreterRenderer prop extension, 2 server actions added (and 2 INSERT actions deleted), 2 specs updated.
</objective>
