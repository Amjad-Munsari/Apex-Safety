## Domain Investigation: Media Capture & Processing

### 1. Browser-side HEIC Conversion
- **Library:** `heic2any` is the most mature choice for client-side HEIC to JPEG/PNG conversion.
- **Performance:** For a typical 5-8MB HEIC file, conversion takes 1-3 seconds on modern mobile hardware (iPad).
- **Implementation:**
  ```javascript
  import heic2any from "heic2any";
  const blob = await fetch(heicUrl).then(res => res.blob());
  const convertedBlob = await heic2any({ blob, toType: "image/jpeg", quality: 0.8 });
  ```

### 2. High-Fidelity Compression
- **Library:** `browser-image-compression`.
- **Target:** 1.2–1.5MB.
- **Constraints:** Must maintain legibility of text labels (e.g., fuse box circuits).
- **Strategy:**
  1. Detect HEIC and convert first.
  2. Apply compression with `maxSizeMB: 1.5` and `maxWidthOrHeight: 2560`.
  3. Validate orientation via EXIF (usually handled by `browser-image-compression` internally).

### 3. Speech-to-Text (STT) via OpenRouter
- **Model:** `openai/whisper-large-v3-turbo` (via OpenRouter).
- **Workflow:**
  1. Capture audio via `MediaRecorder` API (WebM/Ogg/WAV).
  2. Send to `/api/proxy/stt` (server-side to hide API keys).
  3. Proxy to OpenRouter `https://openrouter.ai/api/v1/audio/transcriptions`.
- **Latency:** ~2-4 seconds for typical 10-second clips.
